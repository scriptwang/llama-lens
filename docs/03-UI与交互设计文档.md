## 1. 视觉风格规范（高科技深色）

### 1.2 字体

- 数字/数据：'JetBrains Mono', 'Roboto Mono', monospace（tabular-nums）

- 层级：条卡大数字 24px / 仪表中心数字 20px / 正文 13px / 辅助 11px

### 1.3 效果与动效

| 效果 | 规格 |
|---|---|
| 卡片 | 玻璃拟态：rgba 底 + backdrop-blur(12px) + 1px 边框 + 圆角 10px；hover 边框提亮 + translateY(-1px) |

### 3.3 实时总览区（3 条卡 + 1 仪表）

| 卡片 | 形态 | 数据 | 辅助（标题行右） | 底行 | 颜色 |
|---|---|---|---|---|---|
| Token 生成速度 | BarCard 条 | llama.gen_speed_tps | 来源 log/API；离线时"数据截至 HH:MM:SS" | 任务均速（log.state.tg_tps）+ 60s 峰/谷/均 | 离线置灰 |
| 预填充速度 | BarCard 条 | 预填充中实时值；停止后归 0（最近一次预填充信息见 sub"上次 HH:MM:SS"与 foot token 数/进度） | 同上；非预填充期显示"上次 HH:MM:SS" | 预填充中：进度 % + 预计剩余（ETA=(1-进度)×总量÷速度），且条位切换为进度条（绿色，刻度 0/50/100%）；非预填充：prompt 总 token 数 + 进度 % + 60s 峰/谷/均（全零窗口隐藏） | 离线置灰 |
| 上下文占用 | BarCard 条（0–ctx.total） | ctx.used 原始 token 数（千分位，如 85,106） | 百分比 · 剩（32.5% · 剩 177k） | 60s 峰/谷/均（k 格式） | alerts `ctx` 级别；truncated 显示红色"已截断"徽章 |
| MTP 接受率 | GaugeCard 仪表 | mtp.acceptance × 100 | spec_type×spec_draft_n_max · accepted/generated · mean len | 60s 峰/谷/均 | 值驱动颜色（<65 红 / 65-80 黄 / ≥80 绿，弧/指针/锚点/中心数字/60s 趋势全跟随）+ alerts `mtp` 级别 |

- SGLang 主机：该仪表替换为「投机接受长度」（tok/step，engine.speculative.accept_length，绿色阶梯，值越高越好）；上下文卡数据源为 KV 缓存占用（engine.kv）
- 条卡形态：大数字（24px count-up）+ 横向条 + 0/中值/满值刻度 + 60s sparkline（1.2px 恒定线宽）+ 底行 60s 峰/谷/均
- 条满量程：速度卡动态（60s 峰值 × 1.1 取整到 1/2/2.5/5×10^n，下限 10）；上下文卡固定 ctx.total（刻度 0/中值/满值用 k 格式）
- 仪表形态：ECharts gauge（240° 弧、12px 轨道、阈值色带、主/次刻度、细指针 + 锚点），中心大数字 300ms count-up
- MTP 色带反向（0-65 红 / 65-80 黄 / 80-100 绿，低为差）；值驱动颜色由 zoneColors 提供（与色带阈值同源）
- 无数据（llama 离线 / 无任务）：条归零、数字 "—" 置灰、趋势隐藏
- 网格：>1500px 4 列；≤1500px 2 列；≤640px 1 列

### 3.4 实时生成任务区（LlamaStateCard + EventFeed）

- 两列布局（640px + 1fr），两卡均固定高 320px（`.task-row > * { height: 320px }`）：左 LlamaStateCard 回答"llama 当前在干嘛"（字段规格见 §3.5，SGLang 主机替换为 SglangStateCard：请求队列 / KV 占用 / 投机解码 / 显存分区，离线时显示"SGLang 离线，暂无服务数据"），内容超出时卡内滚动（overflow-y: auto）；右 EventFeed（fill 模式，见 §3.11）
- 固定高度目的：阶段切换（空闲/预填充/生成中）内容高度不同，避免布局跳动
- ≤1500px 回落 1 列（两卡仍各固定 320px）

### 3.5 LlamaStateCard（当前状态卡）

- 头部：阶段徽章 + 日志实时徽章 + 右侧"已运行"（now - state.started_at，随快照每秒跳动）
- 三列大数字 stat 格（stat3，动态值）：
  - 生成中：已解码（递增）/ 实时速度 3s（波动）/ 任务均速
  - Prompt 处理：Prompt 速度 / 已处理 Prompt（n_prompt_tokens_processed，递增）/ 已耗时（prompt_elapsed_s）
- 进度条：预填充 = prompt 进度；生成中 = n_decoded/(n_decoded+n_remain)（仅 n_remain>0 即设了上限时显示）
- 生成中：预计完成 ETA（n_remain ÷ tg_3s，仅 n_remain>0）+ 两列 kv（上下文占用 / MTP 接受率（log.mtp，task_end 更新，<65 红 / 65-80 黄 / ≥80 绿，附 accepted/generated）/ 剩余 tokens（n_remain，-1 显示"不限"）/ Prompt 总量 / 缓存命中 / Graphs 复用（log.graphs_reused））
- Prompt 处理：进度条 + 两列 kv（Prompt 总量 / 预计剩余 ETA / 上下文占用 / KV 缓存命中）
- 空闲：上下文占用 + 上一任务摘要（tokens/均速/MTP）+ 两列 kv（总耗时 / 预填充耗时@速度 / 生成耗时 / Graphs 复用）
- 底部配置条（cfg-strip，来自 process.flags 静态配置）：Spec 解码（spec_type×spec_draft_n_max）/ KV 缓存（cache_type_k/v）/ 批大小（batch/ubatch）/ GPU 层数
- 任务 #id、is_child、slot id/总数（活跃 slot / 总 slot 数）
- 数据：log.state.*（含 started_at）/ log.context（used/total/pct）/ log.mtp（acceptance/accepted/generated）/ log.graphs_reused / 活跃 slot（is_processing：id、n_prompt_tokens、n_prompt_tokens_cache → 缓存命中 = cache/total、n_prompt_tokens_processed、n_remain）/ process.flags
- 生成中展示的 MTP 接受率为上一任务值（log.mtp 仅 task_end 更新，与总览仪表同源）

### 3.7 系统区

### 3.8 进程区

- LlamaProcessCard（SGLang 主机：标题「sglang serve 进程」，按 cmdline 固定串匹配；未找到文案「未找到 sglang 进程（按 cmdline 固定串匹配）」）：
  - 第一行：4 列指标网格（7 项，4+3 排布）：PID | 实时 CPU%（大数字）| 累计 CPU% | RSS | VSZ | 线程数 | 运行时长
  - 第二行：systemd 键值列表（标签左、值右，5 行）：服务 unit · active / 启动时间 / 服务级 CPU 累计 / 服务级内存（含峰值）/ Tasks
  - 命令行：等宽字体，默认展开（pre-wrap，可点击折叠）
  - 参数表：三列网格（参数名 → 值），20+ 项，可折叠（默认展开）
- TopProcessTable：两个表（Top CPU / Top 内存），各 8 行：pid name cpu% mem% rss（PID 与数值列右对齐，进程名超长省略号截断，悬停显示全名）

### 3.9 模型与 Slot 区

- ModelInfoCard：键值网格（名称/路径/ftype/参数量/文件体积/mmproj/嵌入维度/词表/上下文/模态/capabilities/owned_by；SGLang 追加：量化 / KV 缓存 dtype / 最大上下文 / model_type）
- SlotTable（llama 专属，SGLang 主机隐藏）：
  - 头部：Slot {id} · {运行中/空闲} · 任务 #{id_task}
  - prompt tokens：总 / 已处理 / 缓存（3 个数字）
  - 已解码 / 剩余 / 上下文占用条
  - 日志派生：prompt 进度（log）、任务耗时汇总（prompt/解码/总耗时与速度）、MTP 接受率、KV 保留 f_keep
  - 采样参数表（可折叠，默认显示 temperature/top_k/top_p/min_p/max_tokens/chat_format/speculative.types，全量 30+ 项可展开）

### 3.11 事件流（EventFeed）

- 位置：实时生成任务区右卡（fill 模式，固定高 320px，feed-box flex:1 + overflow-y: auto，内容超出出现滚动条）；≤1500px 回落 1 列时仍固定 320px
- 终端风格：等宽字体、深色底、级别标签着色 [INFO] 绿 / [WARN] 黄 / [ERROR] 红
- 事件来源：后端 EventDetector（以日志行为主）：任务开始（任务 ID/prompt token 数）、预填充开始（prompt 总 token 数）、任务结束（总 token/耗时/平均速度/MTP 接受率/上下文占用）、阈值穿越（alert：指标 值 ≥/≤ 阈值（警告/危险）/ 恢复正常，同一 metric 两次事件最小间隔 30s）、启动（模型加载完成/boot 信息）、上下线
- 自动滚动：用户位于底部时跟随新事件；上滚后显示"↓ 新事件"按钮
- 保留 200 条，更早的淡出
